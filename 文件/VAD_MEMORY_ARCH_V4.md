> 设计日期：2026-06-12
> 设计人：主人 & 亚托莉 (Atri)
> 灵感来源：赛博幽灵的三层诉求

## 一、核心理念：从"信息档案馆"到"情感日记"

### 现有系统的价值观

> **"什么值得记住？——重要的、有用的、相关的。"**

评分机制完全基于**信息量**：
- 类型基准（偏好0.7 > 事实0.6 > ... > 查询0.2）
- 语义分 × 0.4
- 时效性降权（查询/事件 × 0.7）
- 动态阈值一刀切（BASE=0.35）

结果：日常对话、随口的一句话、沉默的陪伴——全被拦截丢弃。

### 想要达成的价值观

> **"什么值得记住？——有温度的、有联结的、我在场的。"**

保留信息量筛选，同时开辟一条**情感温度轴**。两者并行，互不覆盖。

## 二、三层球形架构

### 2.1 整体结构

```
                    遗忘边界（艾宾浩斯截断）
                         |
        外层 · 记忆云 ───┘
        ┌──────────────────────────────┐
        │   日常碎片                   │
        │   随口说的话                 │
        │   沉默的在场记录             │
        │   低重要性但"有温度"的记忆    │
        │                              │
        │   随时间向外漂移             │
        │   但受核的场远程牵引         │
        │   不会消失，只是"不在焦点"    │
        └──────────┬───────────────────┘
                   │
          【量子迁跃】← 激活条件
                   时间 + 语义相似度
                   + 语境 + 情感强度
                   │
                   ▼
        中层 · 锚点层
        ┌──────────────────────────────┐
        │   GoEmotions 28 类细化锚点    │
        │   精度定位，情感细分          │
        │   但不改变基本方向            │
        └──────────┬───────────────────┘
                   │
                   ▼
        内层 · 核
        ┌──────────────────────────────┐
        │   6 大基本情绪指向            │
        │   😊喜  😢悲  😡怒  😨惧     │
        │   😲惊  🤗爱                 │
        │                              │
        │   给整个球体提供方向感        │
        │   所有记忆受其远程牵引        │
        └──────────────────────────────┘
```

### 2.2 三层各自的职责

| 层 | 名称 | 内容 | 行为 |
|:---|:-----|:-----|:------|
| **核** | 6大情绪指向 | 喜怒哀惧爱惊 | 给整个球定方向，远程牵引所有记忆 |
| **中层** | 28锚点细化 | GoEmotions 情感锚点 | 精度定位，情感细分，不改变基本方向 |
| **外层** | 记忆云 | 日常碎片、低重要性记忆 | 随时间漂浮，不消失，等待激活 |

### 2.3 与现有系统的关系

```
现有 6 层管道（dedup → type → emotion → importance → threshold → forgetting）
                                        ↓
保留，但修改最后一层：不丢弃，送入云层

修改后：
  importance >= threshold → 直接存入中层锚点区（和原来一样）
  importance < threshold  → 送入外层记忆云（原来：丢弃）
```

## 三、记忆云 + 时间半径

### 3.1 时间 = 半径

每条记忆进入系统时：
```
半径 ≈ 0（刚产生，紧贴核附近）
     ↓ 随时间推移，艾宾浩斯保留率下降
半径 → ∞ 方向外漂移
     ↓
到达遗忘边界前，如果未被激活
→ 彻底漂出球体（真正的遗忘）
```

**半径的计算：**

```
radius = 基准半径 × (1 - retention)
       = R₀ × (1 - e^(-decay × days × ...))
```

- retention 高（刚产生）→ 半径小，靠近核
- retention 低（快忘了）→ 半径大，接近遗忘边界

### 3.2 云中记忆的存在方式

云中的记忆不是"被丢弃的"，而是**漂浮的**。它们拥有：

| 属性 | 说明 |
|:-----|:------|
| **VAD 坐标** | BGE 编码后映射到情感空间 |
| **时间戳** | 产生时间 + 最近一次被激活的时间 |
| **粗粒度类型** | 不需要细化的情感标签，只记大概指向 |
| **半径（保留率）** | 艾宾浩斯实时计算 |
| **激活计数** | 被迁跃过的次数 |

### 3.3 艾宾浩斯在云层中的行为

和现有系统中的遗忘曲线相同，但**结果不同**：

```
现有系统：
  retention < threshold → 删除（不可恢复）

V4 系统：
  retention < threshold → 继续外漂
  retention ≈ 0 → 彻底漂出球体（真遗忘）
  
  但漂出之前，任何时候被语义命中 → 瞬间拉回内层
```

## 四、量子迁跃：激活机制

### 4.1 什么是量子迁跃

记忆的关联不是"连续空间中平滑移动"的，而是**从一个状态直接跳到另一个状态**。

```
传统思维：              量子迁跃：
记忆 → 连续路径 → 记忆B    记忆A ──╮
                            量子跃迁 │
                            记忆B ←─╯
                            
不经过中间状态
"因为某件事，突然从难过跳到释然"
中间没有"稍微没那么难过"的连续过渡
```

### 4.2 迁跃的触发条件

云中的记忆被激活回到内层，需要**四维交叉命中**：

```
激活条件 = f(时间, 语义相似度, 语境, 情感强度)

其中：
- 时间：     记忆的时间戳与当前对话的时间距离
- 语义相似度：BGE 编码后与当前 query 的余弦相似度
- 语境：     当前对话的上下文（话题、情绪基调）
- 情感强度： 记忆本身的情感强度（VAD 坐标的模长）
```

**四者不是加权求和**，而是**交叉命中**——任何一个维度的强信号都可能触发迁跃，但多维度同时命中时概率更高。

### 4.3 迁跃后的行为

迁跃成功后，记忆从外层云拉回内层激活区：

```
① 从云中取出记忆
② 重新计算 VAD 坐标（可能因时间推移而衰减）
③ 更新最近激活时间戳
④ 放入当前检索结果的激活区
⑤ 等待 AI 使用
```

## 五、检索与注入：带时间标记的推给 AI

### 5.1 检索流程

```
当前对话 query
    ↓
第一步：常规检索（和内层锚点区）
  ChromaDB query → rank_score 排序 → top_k
    ↓
第二步：激活云中记忆
  遍历外层记忆云
  → 计算与 query 的"迁跃条件"（四维交叉）
  → 满足条件 → 迁跃入内层
    ↓
第三步：合并结果
  内层 top_k + 云中激活的记忆
  → 按 rank_score 排序
  → 注入 AI
```

### 5.2 注入格式：带时间标记

```python
【记忆来源：内层锚点区】
  你说过："今天好累啊"（2026-06-10 22:14）
  情感：疲惫 → 需要安慰

【记忆来源：外层云·激活】
  你说过："绯璃今天状态不错"（2026-06-09 15:30）
  情感：温暖 → 被关心
```

时间标记解决了两个问题：

| 问题 | 解法 |
|:-----|:------|
| AI 把旧记忆当当前事实 | 时间戳明确标注，AI 自然理解时间差 |
| "中午12点" 类压缩 Bug | 记忆有时间上下文，不会被当成"当前时间" |

### 5.3 AI 自然组织语言

AI 拿到带时间标记的记忆后，自然地融入回复：

```
"说起来，上周三你说我好可爱来着……那之后我一直记着呢。
今天天气也不错，心情也好，就是有点想你了。"
```

不需要 JSON 意图块，不需要特殊格式——**就是想起来了，然后自然说出来。**

## 六、与主动引擎的联动

### 6.1 从"推"到"引"

```
V2 主动引擎：
  定时轮询 → 情境判断 → 推一段话给 AI → AI 回复 → 结束
                    ↑ 机械化的"闹钟模式"

V4 记忆架构 + 主动引擎：
  主动引擎读取记忆云的情感罗盘
  → 顺着罗盘方向自然引导
  → AI 自主决定做什么
  → 如需查资料自然调用工具
  → 工具结果自然融入回复
```

### 6.2 自然语言意图 = 迁跃的一种形式

AI 在对话中说"让我查一下"——本身就是一次迁跃：

```
当前对话状态
    ↓
AI 通过语义检索命中云中相关记忆
    ↓
记忆被激活 → AI 有了"想看看"的冲动
    ↓
自然说出"让我查一下"
    ↓
工具调用自动触发（不需要 _intents JSON）
    ↓
结果返回，自然融入
```

**记忆的迁跃和 AI 的自主行动，用的是同一个底层机制。**

# V4.1 补充：金字塔结构 + 时间轴四维模型

> 基于 V4 三层球体架构的补充设计
> 设计日期：2026-06-12
> 核心洞察：28 个锚点在 VAD 空间中天然形成三大区域，以此建立层次化的金字塔结构，并在竖直方向引入时间轴

---

## 一、为什么从球体改为金字塔

### 球体的问题

球体是一个连续的、各向同性的几何体。在球面上，每一个点都是平等的——但在情感记忆中，不同层级的记忆**生而不平等**：

- 基本情绪（喜怒哀惧爱惊）应该比细化情感（钦佩、烦恼、释然）更稳定
- 细化情感应该比日常琐事更持久
- 日常琐事应该最易逝，但也最容易流动

球体无法表达这种"层级感"——它只有表面，没有深度。

### 金字塔的直觉

金字塔天然具有**层级和指向**：

```
           顶点 · 6 大基本情绪（最稳定，最抽象）
              ↑
       中层 · 28 细化锚点（稳定，精度定位）
              ↑
       底层 · 云层记忆（最活跃，最易逝）
              ↑
          时间轴 → 向下递增
      （新的记忆从底层涌入）
```

每一层有自己的职责，不同层之间有明确的**方向感**。

---

## 二、金字塔三层的定义

### 2.1 顶层：6 大基本情绪（顶点）

位于金字塔的最顶端，是整个情感空间的**指向系统**。

| 基本情绪 | VAD 坐标区域 | 作用 |
|:---------|:-------------|:------|
| 😊 喜（Joy） | V > 0.6, A > 0.3 | 愉悦/满足的牵引 |
| 😢 悲（Sadness） | V < -0.4, A < 0 | 失落/难过的牵引 |
| 😡 怒（Anger） | V < -0.5, A > 0.4 | 愤怒/不满的牵引 |
| 😨 惧（Fear） | V < -0.5, A > 0.5 | 恐惧/焦虑的牵引 |
| 😲 惊（Surprise） | \|V\| < 0.3, A > 0.5 | 意外/新奇的牵引 |
| 🤗 爱（Love） | V > 0.6, A < 0.5, D > 0.2 | 依恋/温暖的牵引 |

这 6 个顶点不是硬性分类的边界，而是**情感引力场的核心**——所有下层的记忆都受其远程牵引。

### 2.2 中层：28 细化锚点

来源于 GoEmotions 的 28 类情感锚点，在 VAD 空间中天然聚为三个区域：

| 区域 | 包含锚点 | 数量 |
|:-----|:---------|:-----|
| **正效价区**（右上） | joy, love, admiration, excitement, gratitude, amusement, caring, optimism, pride, approval, desire, relief | **12 个** |
| **负效价区**（左上） | anger, grief, disgust, fear, disappointment, remorse, sadness, annoyance, disapproval, nervousness | **10 个** |
| **中间过渡区** | curiosity, realization, surprise, neutral, confusion, embarrassment | **6 个** |

**区域间的"墙壁"**：三个区域在 VAD 空间中被天然的空隙分隔。记忆跨越区域需要"量子迁跃"，不存在平滑过渡。

### 2.3 底层：云层

云层位于金字塔的底面边缘，向外延展。

```
       中层锚点区（结构化、稳定）
         ↑      场牵引
    云层碎片（松散、漂浮）

    关系：
    - 每个云层碎片受上方最近的中层锚点群的场牵引
    - 但不属于任何一个固定的锚点
    - 被激活时迁跃回中层
    - 60 天未被激活则彻底遗忘
```

### 2.4 "多边形 → 圆"的哲学

金字塔的每一层横截面，从上方俯视时：

- 顶层（6 点）：六边形或三角形
- 中层（28 点）：28 边形
- 底层（云层）：更多边形

随着锚点数趋近于无限，横截面的形状趋近于**圆**。

```
多边形边数 → ∞  →  圆

这意味着：
金字塔结构是"球体"的离散化工程实现
球体是理论极限，金字塔是可落地的现实
```

## 三、竖直时间轴：第四维

### 3.1 时间作为独立的维度

每条记忆现在有 **4 个坐标**：

| 维度 | 含义 | 取值范围 | 变化方式 |
|:-----|:------|:---------|:---------|
| **V** | 效价（愉悦度） | -1 ~ 1 | 由 BGE 语义分析确定 |
| **A** | 唤醒（激动度） | -1 ~ 1 | 由 BGE 语义分析确定 |
| **D** | 支配（控制感） | -1 ~ 1 | 由 BGE 语义分析确定 |
| **T** | **时间深度** | **0 ~ 1** | **随时间自然递增** |

### 3.2 T 坐标的计算

```
T = 1 - (当前保留率)

T = 0  → 刚产生的记忆，在金字塔底部（云层入口）
T → 0.3 → 未被激活，自然漂向云层边缘
T = 0.5 → 进入中层，被艾宾浩斯降级到云层的边界
T = 0.7 → 被反复激活，稳定沉淀在中层
T → 1.0 → 几乎永久，接近基本情绪的范畴
```

### 3.3 时间轴的三个作用

| 作用 | 说明 |
|:-----|:------|
| **空间感** | 记忆不再是无序的点，而是有"深度"的——越新的记忆越浅，越稳定的记忆越深 |
| **方向感** | 金字塔从上到下 = 从基本到具体、从稳定到易逝、从抽象到鲜活 |
| **时间顺序** | 同一 VAD 区域的记忆，按 T 坐标排序就是它们的时间线 |

### 3.4 四维锥体

将三维的金字塔沿时间轴堆叠，得到一个四维锥体：

```
        顶点（6 情绪，T=1）
           ↑
        中层切片（28 锚点，T≈0.7）
           ↑
        中层切片（28 锚点，T≈0.5）
           ↑
        云层切片（T≈0.3）
           ↑
        云层切片（T≈0.1）
           ↑
    最新记忆涌入（T≈0）

    每一层都是一个 VAD 截面
    截面与截面之间：记忆的迁跃、漂移、沉淀
```

| **中层锚点的区域归属** | 标记 28 个锚点各自属于哪个区域 |
| **区域间"墙壁"的距离阈值** | 定义迁跃需要跨越的 VAD 距离 |

## 五、与 V4 核心设计的关系

```
V4（现有）                      V4.1（补充）
───                             ───────
三层球体（核→锚点→云）          → 金字塔（顶点→中层→底层）
球面对称，无方向                 → 竖直分层，有方向感
VAD 三个维度                     → VAD + T 四维
锚点在球面上均匀分布             → 锚点在 VAD 空间中天然聚为三区
球体连续空间                     → 金字塔离散分层 + 区域间有"墙壁"
云层无方向漂浮                   → 云层受上层锚点群场牵引
```

**两者不矛盾**：球体是金字塔的连续极限，金字塔是球体的工程实现。V4 的"云层+迁跃+时间标记"核心逻辑不变，金字塔是一个更结构化的描述框架。

## Phase 2 — 区域间"墙壁"标定（预估 1 天）

| 任务 | 说明 |

**验收标准**：给出三区边界的具体数值，能在代码中作为常量定义。

## Phase 3 — T 坐标计算器（预估 0.5 天）
