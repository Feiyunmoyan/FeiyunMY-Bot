## 📋 项目概览

Vue 3 + Vite + Tailwind CSS 前端项目，通过 FastAPI 后端服务挂载，访问路径为 `/admin/`。

## 🏗️ 目录结构

```

```

## 🎨 主题系统

- **暗红色主题（默认）**：主色 `#8B1A2B`，背景 `#1A1012`，文字 `#EDE0D4`
- **浅色主题**：暖白背景 `#FBF8F7`，主色不变
- 切换方式：顶栏 `⋯` 菜单 → 浅色模式/暗红色模式
- 保存在 `localStorage`（`feiyunmy-theme`）
- CSS 变量定义在 `style.css`，通过 `.dark` 类切换

## 🗺️ 页面路由

由 `App.vue` 管理，顶部 `TopBar` 有三个页面切换按钮：
- **仪表盘** → Dashboard（左侧边栏导航 10+ 个子页面）
- **Chat** → ChatPage（会话列表 + 聊天区域）
- **工作空间** → WorkspacePanel（左侧空间列表 + 右侧内容）

## 📝 注意事项

1. **Chat SSE 解析**：`useChat.js` 中按 `\n\n` 分割 SSE 事件，同一事件内多行 `data:` 拼接后解析 JSON，兼容工具结果含换行符的情况
2. **文件上传**：前端上传 → 后端返回 `file_id` → 发送消息时带上 `file_ids` → 后端自动嵌入内容到消息
3. **多提供商**：提供商数据统一走后端 `/api/providers`，不再使用 `localStorage`
4. **构建后**：需重启 FastAPI 服务才会加载新构建的前端
5. **Markdown**：AI 回复使用 `marked` 库渲染 Markdown，用户消息保持纯文本
